# Rink Riot

A dark, neon teal-and-magenta [Omarchy](https://omarchy.org/) theme with a
retro roller-rink vibe.

![Preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/pfunderdome/omarchy-rink-riot-theme.git
```

Or clone it manually into `~/.config/omarchy/themes/`:

```bash
git clone https://github.com/pfunderdome/omarchy-rink-riot-theme.git \
  ~/.config/omarchy/themes/rink-riot
omarchy theme set "Rink Riot"
```

## What's included

- `colors.toml` — the full color palette (dark mode, teal accent `#00ae8e`)
- `backgrounds/` — 9 roller-rink-themed wallpapers, cycle with `omarchy theme bg next`
- `icons.theme` — Yaru-prussiangreen icon set
- `preview.png` — desktop preview shown in the theme switcher
